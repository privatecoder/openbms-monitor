---
title: Parameters
short: The packs' settings: limits, delays, balancing and function switches. The app reads and compares them and writes them on a click, to one pack or the same change to several; also serial numbers, the BMS clock, the CAN protocol and the calibration. Visible only when maintenance functions are switched on.
related: topic.buses, topic.switches, topic.paramWrite, topic.calibration, topic.control
---
- **Read from packs:** via the RS485-1/2 bus (19200 baud). The CAN socket does not know the command in the original firmware; packs with patched firmware (from MAINT 1.5.2/1.6.3) report their parameters there too, each pack at its address and by its own firmware, without halting the master. Their column then says “CAN”. There the pack also shows its serial numbers; then the app checks the board as on the RS485-1/2 bus, stores the state and writes via the CAN socket too. Without a unique BMS serial number it only reads, and nothing is stored. If a pack does not answer there, it lacks the patch or is not reachable; then use the RS485-1/2 bus. The two release bits in function switch 0 are explained in “Patched firmware: release bits”. A **master** that polls its slaves (DIP 0 with slaves) does not answer on the RS485-1/2 bus. It becomes reachable once it stops polling: with patched firmware via “Halt master” in the maintenance area (then “Release master”), otherwise with DIP 5–8 set OFF or briefly alone on the bus; or take its values from a BatteryMonitor export.
- **Open export:** XML files from BatteryMonitor (export parameters). Values count by position, not by name. If the names do not match the known order, the app warns: such an export comes from another BatteryMonitor version and must not be written back.
- **Comparison:** every source is a column. Values that differ from the majority are marked; “Only differences” hides everything equal.
- **Save:** a pack's read values can be saved as BatteryMonitor XML (folder `parameters` in the app data).
- **Last state (also without a connection):** shows per pack the last stored state of the chosen installation as a column, with its date and whether it was read or written. It is the state of the current board at that address; if there is none of it, the column shows the newest and says “previous board” or “board unclear”. Comparison, datasheet check and XML save work with it; writing needs a connection with that installation. With “View only” you can read but not write.
- The names are corrected: BatteryMonitor machine-translates from Chinese (“Monomer” = cell, “pressure” = voltage, “Equalization” = balancing). Hover a name to see the original BatteryMonitor name.
