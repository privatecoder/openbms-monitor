---
title: Allow writing via the CAN socket
short: On: write permission applies to “Write parameters and switches”, “Set the hard stop at a recharge pause” and “Save the master's CCL decrease step” via the CAN socket, where supported by this pack. Off: these writes are blocked, reading still works. It can be switched back on only via the RS485-1/2 bus or through this pack's enabled display port.
related: topic.switches
