---
title: Allow on/off, restart and clock via the CAN socket
short: On: allowed are “Set clock”, “On/off”, “Set pack lock (addressed off)”, “Release pack lock (addressed on)” and “Restart” via the CAN socket. Off: locked there; it still works via the RS485-1/2 bus. Change only via the RS485-1/2 bus or on the display. Only the first MAINT 1.6, supported for now, works the other way round (0 allows).
