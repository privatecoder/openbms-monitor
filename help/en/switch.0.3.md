title: Lock of on/off, restart and clock via the CAN socket
short: Only the first MAINT 1.6 (V1_6_CUTOFF, supported for now): 1 (on) locks on/off, restart and setting the clock there together, 0 (off) allows them; reading the clock always works. Change only via the RS485-1/2 bus or on the display.
