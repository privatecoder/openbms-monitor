---
title: Allow on/off, restart and clock via the CAN socket
short: EMU1101-EXT, applies together to “Set clock”, “On/off”, “Set pack lock (addressed off)”, “Release pack lock (addressed on)” and “Restart” via the CAN socket: 1 (on) allows, 0 (off) locks. Change only via the RS485-1/2 bus or on the display. Only the first MAINT 1.6, supported for now, works the other way round.
