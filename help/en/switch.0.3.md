---
title: Block on/off, restart and clock setting via the CAN socket (MAINT 1.6)
short: On the first MAINT 1.6 build, On (1) blocks these commands: “Set clock”, “On/off”, “Set pack lock (addressed off)”, “Release pack lock (addressed on)” and “Restart” via the CAN socket. Off (0) allows them. Change only via the RS485-1/2 bus or through this pack's enabled display port.
related: topic.switches
---
