---
title: Release of on/off, restart and clock via the CAN socket
short: EMU1101-EXT with on/off and the clock via the CAN socket: 1 (on, as with the old value FF) allows on/off, restart and setting the clock there together, 0 (off) locks them; reading the clock always works. Change only via the RS485-1/2 bus or on the display.
