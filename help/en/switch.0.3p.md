---
title: Allow on/off, restart and clock setting via the CAN socket
short: On (1) allows the commands this pack supports: “Set clock”, “On/off”, “Set pack lock (addressed off)”, “Release pack lock (addressed on)” and “Restart” via the CAN socket. Off (0) blocks those commands on this socket; they still work via the RS485-1/2 bus. Change only via the RS485-1/2 bus or through this pack's enabled display port.
related: topic.switches
