---
title: Release of on/off, restart and clock via the CAN socket
short: EMU1101-EXT with power/RTC in the build (image flag bit 1), applies together to “Set clock”, “On/off”, “Set pack lock (addressed off)”, “Release pack lock (addressed on)” and “Restart” via the CAN socket: 1 (on, as with the old value FF) allows, 0 (off) locks. Change only via the RS485-1/2 bus or on the display.
related: topic.switches
