# Help content

One Markdown file per help id and language (`de/<id>.md`, `en/<id>.md`), e.g. `param.P0`, `switch.bg6.b4`,
`alarm.ev2.b1`, `value.soc`, `topic.soc-calibration`. Front matter: `title`, `short` (popover text), `related`.
The build fails if an id used by the UI is missing in a language.
