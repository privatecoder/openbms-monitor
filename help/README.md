# Help content

Generated by `tools/gen_help.py` (topics, values, alarms) and `tools/param_help.py` (parameters, switch bits); do not
edit the pages here. One Markdown file per help id and language (`de/<id>.md`, `en/<id>.md`), e.g.
`param.cell_difference_fault`, `switch.0.3`, `alarm.ev1.b0`, `value.soc`, `topic.connection`. Front matter: `title`,
`short` (popover text), `related`. `app/src/helpIds.test.ts` checks that every topic/value/status id the UI names and
every `related` id exists in both languages.
